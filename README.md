# Tiny Renderer

Project for implementing a c++ native software renderer based on this [course](https://haqr.eu/tinyrenderer/).

Initial project setup taken from the courses [github repo](https://github.com/ssloy/tinyrenderer/tree/706b2dfecff65daeb93de568ee2c2bd87f277860). 

To execute the renderer on a windows machine just run `run.bat`. It will generate a image `framebuffer.tga` and open it in the systems default app. 

Dependencies like the required language and cmake version will be added later here.
